# Printer Password Recovery Prototype

## Описание

Экспериментальный Playwright-скрипт для автоматизированной проверки вариантов пароля в веб-интерфейсе устройства. Проект использовался как исследовательский прототип для анализа формы входа, поведения iframe и реакции интерфейса на неуспешные попытки авторизации.

## Что внутри

- `printer_bruteforce.py` — основной многопоточный сценарий перебора;
- `diagnose_page.py` — вспомогательная диагностика DOM, iframe и селекторов;
- `requirements.txt` — минимальный набор зависимостей.

## Особенности

- запуск в `headless` и диагностическом режиме;
- работа через Playwright с обработкой диалогов и сетевых ошибок;
- настройка длины пароля, набора символов и числа потоков;
- сохранение служебной отладочной информации при локальных экспериментах.

## Запуск

```bash
pip install -r requirements.txt
playwright install chromium
python printer_bruteforce.py
```

Для отладки:

```bash
python printer_bruteforce.py --test
python diagnose_page.py
```

## Ограничения

Проект опубликован как исследовательский архив. Внутренние адреса и диагностические снимки интерфейса исключаются или подменяются на безопасные значения при публикации.

Использовать такой инструмент допустимо только на собственных устройствах или при наличии явного разрешения владельца.
